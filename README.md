# 🏏 Cricket Scorer App

An intuitive cricket scoring application designed to track live match scores, ball-by-ball commentary, player statistics, and match summaries—inspired by CricHeroes.

---

## 🌟 Key Features

* **Live Ball-by-Ball Scoring:** Easily record runs, extras (wides, no-balls, byes, leg-byes), and wickets.
* **Innings Tracking:** Monitor total runs, overs bowled, current run rate, and required run rate.
* **Match Summary & Scorecard:** Detailed batting and bowling statistics for both teams.
* **Undo Feature:** Correct accidental entries on the fly.
